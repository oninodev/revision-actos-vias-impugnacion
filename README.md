# Revisión de los actos administrativos y vías de impugnación

Material interactivo de Derecho Administrativo, publicado como sitio estático en GitHub Pages.

## Contenido

- `index.html`: archivo original `01_revision_actos_vias_impugnacion.html`, conservado sin modificaciones.
- `.nojekyll`: sirve el sitio directamente, sin procesamiento de Jekyll.

## Publicación

Configurar GitHub Pages para desplegar desde la rama `main`, carpeta raíz (`/`).

## Uso local

Abrir `index.html` en un navegador. El progreso se guarda en el almacenamiento local del navegador.
